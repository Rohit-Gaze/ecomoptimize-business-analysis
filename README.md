# EcomOptimize — E-commerce Business Performance Analysis

## Project Overview

EcomOptimize is a self-initiated portfolio case study investigating checkout abandonment, payment failures, product returns, and delayed refunds in a hypothetical e-commerce business.

This project uses synthetic data to demonstrate Business Analyst and Data Analyst skills through KPI analysis, data quality checks, SQL practice, and process improvement recommendations.

- **Project type:** Portfolio case study
- **Reporting period:** January–December 2025
- **Tools:** Microsoft Excel, SQL, Power BI starter materials, Lovable

## Business Problem

Checkout friction and payment failures can lead to lost sales. Product returns and delayed refunds can also affect customer satisfaction and operational efficiency.

The goal is to analyze these processes, identify potential bottlenecks, and recommend measurable improvements.

## Project Objectives

- Analyze checkout funnel performance and abandonment.
- Examine payment failures and relevant KPIs.
- Review product returns and refund turnaround.
- Perform data quality checks.
- Document business requirements, user stories, and UAT test cases.
- Recommend process improvements based on the analysis.

## Tools and Deliverables

| Tool | Deliverable |
|---|---|
| Excel | Synthetic data, KPI analysis, data quality checks, summaries, and dashboard-style reporting |
| SQL | Practice queries using a separate sample dataset |
| Power BI | Starter data, suggested measures, and dashboard-building instructions; no completed PBIX report yet |
| Lovable | Portfolio website presenting the case study |

## Analysis Approach

1. Define the business problem and objectives.
2. Identify stakeholders and relevant KPIs.
3. Review data quality and prepare the data.
4. Analyze checkout, payments, returns, and refunds.
5. Identify potential process bottlenecks.
6. Document findings and propose improvements.

## Recommendations to Evaluate

- Simplify the checkout experience.
- Investigate common payment failure reasons.
- Improve return-policy clarity.
- Track refund turnaround and overdue cases.
- Monitor business KPIs through regular reporting.

These are proposed improvement areas; their effectiveness must be validated rather than assumed.

## Limitations

- All business data is synthetic and does not represent a real company.
- The SQL file uses a separate practice dataset and does not reproduce the full Excel dataset.
- The Power BI materials are a starter pack, not a completed interactive report.
- Findings are illustrative, not verified real-world business outcomes.
